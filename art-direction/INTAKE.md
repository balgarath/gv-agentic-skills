# Intake - art-direction skill

Deposit verified findings here before the session ends; never edit the
reference files mid-task. The merge pass (`maintaining-skills`) integrates
entries into their canonical homes, human-gated.

Before depositing: is this true for every project, or one way that worked on
one project? The second kind is still welcome; say which project, and it
will land in `projects/` or as a technique, not a rule.

Entry format:

```
## <date> | <fact|trap|measurement|conflict|gap> | proposed home: <file section>
<claim in one paragraph; how it was verified; exact version/scene; cost if known>
```
